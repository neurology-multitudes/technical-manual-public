# Public Version of Multitudes Technical Manual

This repo contains the final rendered documents to publish both html and pdf version of the Multitudes Technical Manual online.
Given UCSF's strict privacy protection guidelines, the repo analysis code needs to remain private for now.
We are working on creating synthetic data, in order to be able to share the anlayses here, in the future.

All analysis code, written by [Julian M. Siebert](https://github.com/julian-m-siebert). Should you have any technical questions--about the anlayses presented *or* the publication pipelinep--reach out to [julian.siebert@ucsf.edu](mailto:julian.siebert@ucsf.edu).
